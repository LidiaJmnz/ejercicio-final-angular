# Angular Final - DWEC

Proyecto final realizado con Angular 19 y Angular Material.

## Requisitos cumplidos

- Navegacion SPA con `RouterModule` (`Inicio`, `Servicios`, `Contacto`) sin recarga de pagina.
- Formulario de contacto con `FormGroup`, `FormControl`, validaciones y eventos (`valueChanges`, `blur`, `submit`).
- Galeria interactiva con imagen principal, miniaturas y resaltado de seleccion.
- Sistema de blog con creacion dinamica de posts y mejoras de editar/eliminar/destacar.
- Cambio de tema claro/oscuro con variables CSS y `signals`.
- Codigo en castellano y sin uso de `any`.

## Tecnologias

- Angular 19
- Angular Material 19
- TypeScript estricto
- Signals de Angular

## Ejecucion en local

```bash
npm install
npm start
```

Abrir en `http://localhost:4200/`.

## Build de produccion

```bash
npm run build
```

El resultado se genera en `dist/angular-final/browser`.

## Tests

```bash
npm test
```
